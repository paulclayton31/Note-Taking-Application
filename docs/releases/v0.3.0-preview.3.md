# Surface Notebook v0.3.0-preview.3

A calmer writing workspace and a dedicated place to organize your studies.

## Download

- **Intel / AMD Surface:** [SurfaceNotebook-windows-x64.exe](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.0-preview.3/SurfaceNotebook-windows-x64.exe)
- **Snapdragon / ARM Surface:** [SurfaceNotebook-windows-arm64.exe](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.0-preview.3/SurfaceNotebook-windows-arm64.exe)

Close the previous app, download the matching executable, and open it. No separate .NET installation is needed. This preview leaves v0.2 as the stable release.

## What's new

- **Home for your notebooks.** Click the Surface Notebook logo for notebook covers, nested folders, breadcrumbs, recent notebooks, stars, global search, and a Continue writing shortcut. Create, rename, and move notebooks/folders through their menus. Home adapts to narrow windows and supports both themes.
- **One compact top row.** The logo, notebook tabs, and minimize/maximize/close controls share a 52-DIP header. The page heading is also shorter, leaving more room for paper. Tabs still represent notebooks, with each notebook's last page remembered.
- **Tab close X fixed.** A centered glyph inside a 40 × 40-DIP target prevents clipping. Tab overflow scrolls horizontally without a scrollbar reducing the button's height. Swipe or use the mouse wheel to reveal more tabs.
- **Touch-friendly zoom.** Tap the footer percentage for a slider, zoom presets, Fit width, and Whole page. Pinch and −/+ remain available. Focus mode preserves writing zoom.
- **Your favorite pens.** Save named combinations of color, thickness, and pressure/monoline style in the pen properties menu. Tap to apply; hold/right-click to rename or remove. Current pen, highlighter, and eraser settings also persist.
- **Duplicate and organize pages.** The page **…** menu and page-row context menus offer Duplicate, Move earlier, and Move later. Mouse/pen users can drag thumbnails to reorder. Duplicates include independent ink/text, paper, and view; reordering preserves the current writing position.

The native pressure-sensitive renderer and touch/palm filtering are unchanged. Fingers continue to navigate without creating ink.

## Existing notes

Your library remains in **%LOCALAPPDATA%\SurfaceNotebook**. Upgrading preview.1 or preview.2 creates **library-preview2-backup.db** before the transactional schema 3 migration. Upgrading v0.2 preserves **library-v02-backup.db**. Notes, paper, views, notebook tabs, and toolbar placement are retained. Older versions cannot directly open the upgraded database. See the [persistence guide](https://github.com/paulclayton31/Note-Taking-Application/blob/main/docs/v0.3-workspace.md#persistence) for rollback details.

## Verification

Windows regression checks cover schema migration/backups, nested folder navigation, search/stars, notebook moves, pen preset persistence without changing existing ink, zoom anchoring/fits, independent page copies, transactional page ordering, restart restoration, and the tab X at 640/960/1440-pixel widths with 100–200% raster scale. Existing ink/history, toolbar input, palm suppression, autosave retry, and killed-process recovery checks remain in place.

The release pipeline builds x64/ARM64, verifies x64 standalone startup, captures all eight screenshots, and verifies uploaded asset sizes before publishing. ARM64 execution and physical Surface Pen latency still need device testing. See the [test and usability review](https://github.com/paulclayton31/Note-Taking-Application/blob/main/docs/reviews/v0.3.0-preview.3.md).
