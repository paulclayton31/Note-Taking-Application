# Surface Notebook v0.3.5

Draw-and-hold shapes and Surface Pen side-button lasso selection.

## Download

- **Snapdragon / ARM Surface:** [Windows ARM64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.5/SurfaceNotebook-windows-arm64.exe)

Close the old app, download the matching executable, and open it. Your library stays at **%LOCALAPPDATA%\SurfaceNotebook**. No separate .NET installation is needed.

## What changed

- **Draw, then hold:** With Pen selected, draw a line, triangle, circle, square, rectangle, or ellipse in one stroke. Keep the tip down and still for **0.6 seconds** to preview a clean shape; lift to finish. Small jitter is tolerated at every zoom. Moving again cancels the preview so you can continue freehand.
- **Undo restores the drawing:** One Undo restores the original pressure-sensitive stroke; a second removes it. The converted shape keeps your ink color and thickness with an even-width outline.
- **Optional snapping:** Draw & hold shapes is on by default and can be disabled in the pen rail's ellipsis menu. The preference saves automatically. Highlighter and ordinary strokes without a hold retain their normal behavior.
- **Side-button lasso:** Hold the Surface Pen side/barrel button before touching the page, then circle objects. The lasso stays active through that gesture even if the button is released early. Your toolbar tool and settings remain selected. Tap the selected objects or their actions button for Copy, Duplicate, Delete, and Paste. Touch blank paper without the button to resume the previous tool.

The top/Bluetooth shortcut button is separate. The lasso shortcut needs a Windows ink driver that reports the barrel button. Physical Surface testing remains necessary for device-specific button behavior and handwriting variety; automated checks cannot reproduce every pen/driver combination.

See the [writing guide](../writing-tools.md) for details. PDF import/export and easier scratch-outs remain available. Database schema **4** and portable page version **3** are unchanged; existing library upgrade backups still apply.

## Verification

Windows regression checks cover rotated/noisy shape fixtures, open arcs and other negative fixtures, hold timing, jitter, moving again, cancellation, shape Undo/Redo, unsnapped handwriting preservation, temporary lasso mode across every tool, selection actions, restoring tool settings, workspace transitions, saved preferences, and restart persistence. The existing library, PDF, scratch-out, input, recovery, and layout suites also run.

Release preflight packages x64/ARM64, validates versions, runs bundled x64 startup/PDF checks, and captures the actual interface. ARM64 is cross-built; runtime checks run on x64.
