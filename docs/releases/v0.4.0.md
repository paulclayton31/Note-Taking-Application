# Surface Notebook v0.4.0

The stable v0.4.0 release brings AI calculations into the writing workspace, improved image paste and touch clipboard access, and reliable selection history.

## Calculate beside your notes

- Calculate opens in a docked panel on the right. Keep writing, scrolling or using your pen while reading the solution.
- Close the panel or press Esc, then choose **Solution** beside the zoom controls to reopen the latest calculation without uploading again.
- Selecting a new problem or starting a typed question replaces the previous calculation. There is no calculation history; the latest panel is retained only for the current app session. Replaced requests are canceled and cannot restore old results.
- Fractions, subscripts and powers render as mathematics. Small supported DC circuits are calculated locally from Gemini's interpreted component graph, with residual and superposition checks. Image transcription still requires review.
- Use your own Gemini key; keep Google project billing disabled for free-tier usage. Upload occurs only when you choose Solve. No automatic retries or paid-model fallback.

## Writing and clipboard fixes

- Paste copied images using Ctrl+V, the mouse menu, or hold one finger still on the page for about 650ms and tap Paste. Movement or pinch cancels the hold.
- Undo/redo no longer restores hidden lasso selection highlights after deselection.

## Validation

Windows application and calculation checks cover dock close/reopen/replacement, writing while the solution is open, late-request cancellation, math rendering, clipboard gestures, storage and exports. Release packaging verifies x64 startup and generates actual interface captures, including wide and compact calculation panels. Gemini tests use simulated HTTP responses; live accuracy depends on the input and the model.

Downloads include standalone x64 and ARM64 executables, SHA-256 checksums and interface screenshots. This is a stable release, not a prerelease.
