# Surface Notebook v0.4.0-preview.4

Introduces **Calculate with Gemini**, replacing Windows handwriting recognition for new calculations.

- Circle handwriting or choose **Select area** for a PDF question, pasted diagram, or any rectangular page region.
- Preview the exact image, add a question, and explicitly choose **Solve with Gemini**.
- Review the interpreted problem, answer, and worked solution. Ambiguous input requests clarification.
- Add the result as an undoable note card, with its source image and explanation saved for offline review.
- Use your own Gemini key, optionally encrypted on your Windows account. Keys are excluded from notes and exports.
- Quota, network, credential, and incomplete-response errors leave notes unchanged; no automatic retries or model fallbacks.

Uses Gemini 3.5 Flash-Lite. **For free-tier use, keep billing disabled on your Google AI Studio project.** The app cannot verify billing settings; billing-enabled projects can incur charges. Free-tier input may be used to improve Google's products. See the [Calculate guide](../calculations.md).

Existing offline calculation cards still open in the legacy editor. Includes the image-paste and undo-selection fixes from previous previews. Uses the same database schema and portable page version as preview.3.

## Downloads

Run `SurfaceNotebook-windows-x64.exe` for Intel/AMD Windows devices, or `SurfaceNotebook-windows-arm64.exe` for Snapdragon/ARM devices. No separate .NET installation is required.

## Validation

The Windows pipeline builds the solution, runs simulated Gemini/clipboard/storage/UI regression tests without external API calls, packages both architectures, and checks standalone x64 startup. End-to-end handwriting accuracy requires a user's real Gemini key and is not established by the automated tests.
