# Surface Notebook v0.4.0-preview.2

Paste images copied from a browser or a screenshot directly onto your notes with **Ctrl+V**, or **right-click the paper > Paste**, with any writing tool active. In a browser, choose **Copy image** rather than Copy image address.

- Pasted images fit the page and are selected so you can move or resize them immediately.
- Lasso copy, duplicate, delete, and cross-page paste include images.
- Image edits support undo/redo and autosave. Images remain available offline and survive restarting the app.
- Page/notebook duplication, portable page export, thumbnails, and PDF export retain images.
- PNG clipboard data retains transparency; standard Windows bitmap clipboard data is also supported.

This preview includes the existing experimental Calculate tool from preview.1.

## Downloads

Download `SurfaceNotebook-windows-x64.exe` for Intel/AMD Windows devices, or `SurfaceNotebook-windows-arm64.exe` for Snapdragon/ARM devices. Run the executable directly. No separate .NET installation is needed.

## Upgrade

The app backs up your existing database to `library-v035-backup.db` before adding image storage (schema 5). Older app versions cannot open the upgraded library. Portable pages now use version 4; this app continues to read versions 1–3. Images are embedded in your notes, with limits of 16 MB per image and 32 MB per page.

## Validation

The Windows release pipeline builds the solution, runs the regression harness (including browser PNG and bitmap paste, image undo/redo, copy/duplicate/delete, persistence, portable page and PDF export), packages both architectures, and checks standalone x64 startup before publishing.
