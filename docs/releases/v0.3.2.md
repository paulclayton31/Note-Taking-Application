# Surface Notebook v0.3.2

Library management, smoother navigation, and quieter writing controls.

## Download

- **Intel / AMD Surface:** [Windows x64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.2/SurfaceNotebook-windows-x64.exe)
- **Snapdragon / ARM Surface:** [Windows ARM64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.2/SurfaceNotebook-windows-arm64.exe)
- [SHA-256 checksums](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.2/SHA256SUMS.txt)

Close the previous app, download the executable for your Surface, and open it. No ZIP extraction or separate .NET installation is required. Your existing library remains at **%LOCALAPPDATA%\SurfaceNotebook**.

## Changes

- **Delete notebooks and pages.** Notebook menus and page actions include Delete with confirmation. Deleting the active page opens its neighbor; deleting the last page returns to the library. Reopening an empty notebook creates a fresh blank page. Deleting all notebooks leaves an empty library across restarts.
- **Copy, duplicate, and paste notebooks.** Use a notebook's menu to Copy or Duplicate. To paste somewhere else, open the destination folder and tap the clipboard button beside New folder. Copies preserve page order, paper, handwriting, text, and views, with independent IDs and unique names. The notebook clipboard is a snapshot kept for the current app session.
- **Close every tab.** The final tab can close to the library. Right-click the tab strip for Close all tabs. Closed tabs stay closed after restarting, and reopening a notebook remembers its last page. Closing tabs while in the library keeps the library visible.
- **Smoother page navigation.** Pixel scrolling and recycling keep native touch panning, while short wheel easing respects system animation settings and stops for direct input. Selecting a page reuses the unchanged list so its scroll position stays steady.
- **Subtler pen icons.** Small Fountain/Ball nibs and slim color indicators replace the circular badges. The active pen retains a quiet highlight, dark colors remain identifiable in dark mode, and the touch targets remain 44 DIPs.

**Deletion is permanent after confirmation.** The ink Undo arrow does not restore deleted pages or notebooks. Closing a tab does not delete notes.

v0.3.1's automatic pen saving, thin vertical rail, color wheel, lasso actions, and undoable scribble erasing remain available. Database schema 3 and version 2 portable pages are unchanged; this release does not require a new schema migration.

## Verification

Windows regression checks cover notebook copy isolation, content/order/views and folder destinations, repeated paste and source deletion, page/notebook deletion, empty-library restart and recreation, final-tab/all-tab closing, page-list stability, pixel wheel movement, and direct-scroll interruption. The existing storage, recovery, input, and pen checks also run.

The release pipeline validates embedded versions, builds standalone x64 and ARM64 executables, checks x64 startup, renders the actual interface, and verifies uploaded assets before publishing. ARM64 is cross-built; native runtime checks run on x64. Physical Surface input and scrolling comfort still benefit from device feedback.
