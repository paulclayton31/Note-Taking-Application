# Surface Notebook v0.4.0-preview.3

Fixes handwriting or text appearing selected again after deselecting it and pressing Undo or Redo.

- History snapshots preserve stroke content and metadata without WPF’s hidden selection flag.
- Undo and redo clear lasso and text-range selection before rebuilding the page. Restoring content does not select it.
- Text-object rebuilds discard selection references before removing their old controls.
- New selections made by the user continue to work normally.

Includes the image-paste improvements from preview.2 and the experimental Calculate tool from preview.1. Download the x64 executable for Intel/AMD Windows devices or the ARM64 executable for Snapdragon/ARM devices.

Uses the same schema 5 and portable page version 4 as preview.2. Existing notes are preserved.

Validation: Windows build and regression checks include recording selected strokes, deselecting them, repeated undo/redo of mixed ink/text content, checking the hidden rendering flag as well as public selection, and selecting again manually. The release pipeline packages both architectures and verifies standalone x64 startup before publishing.
