# v0.4.0-preview.6 — Typeset mathematics and calculated DC circuit answers

- LaTeX rendering provides stacked fractions, subscripts and superscripts in review, saved cards, captures and PDF export. Wide equations scroll in review.
- Small DC resistor circuits with independent sources are transcribed as component graphs and solved locally using modified nodal analysis. The app generates node and superposition steps from the numerical result, replacing contradictory model answers.
- Interpreted component endpoints are shown for review. Residual and superposition checks validate the graph calculation; they cannot validate image transcription.
- Other problem types continue to use AI solutions. No extra API call or paid fallback was added.

Regression fixture: 8 V, resistors 2/4/2/6 ohms, 6 A entering the middle node. Output is 60/7 V (8.57143 V); superposition contributes 24/7 and 36/7 V. A simulated AI answer of 18 V must be replaced by the local result. Rendering checks cover fractions, subscripts, powers and note cards. No live Gemini accuracy claim.

- Hold one finger still on the page for about 0.65 seconds to open page actions and Paste. Moving, pinching, releasing early, or pen proximity cancels the hold. Uses the existing clipboard path for images, text and notebook objects.
