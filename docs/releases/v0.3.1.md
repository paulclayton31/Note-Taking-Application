## Changes

- **Pen edits now save to the selected pen.** Color, thickness, and pressure/monoline changes persist when switching pens and after restarting. The old detached-current-pen behavior is removed, and previous current settings are preserved when loading older preferences.
- **Thin vertical tool rail.** A 64-DIP floating rail replaces the wide inspector. It overlays the page without resizing it, has a vertical thickness slider, and compacts for short windows. It retains the tap-active-tool and close-on-writing behavior.
- **Add pen and a color wheel.** The + button opens a new-pen flow with a wheel, brightness, name, and style. Canceling leaves current pens unchanged. Recoloring an existing pen saves automatically. Optional hex input remains available.
- **Fountain and Ball buttons.** Fountain keeps native pressure-sensitive ink; Ball uses monoline. Existing handwriting is unaffected by changes.
- **Easier handwriting scratch-outs.** Shorter back-and-forth scratches, flatter gestures, diagonal directions, and partial vertical coverage are recognized more readily. Ordinary ink fixtures and long strokes outside the scratched region remain protected.
- **Undo remains the recovery path.** The back arrow restores both erased content and the scratch mark; a second Undo removes the scratch. Scribble erasing can be disabled in tool options.

The Home library, folders, paper settings, lasso copy/duplicate/delete/paste, page workflows, offline autosave, and committed-note recovery remain available.

## Existing notes

Your library remains at **%LOCALAPPDATA%\SurfaceNotebook**. v0.3.1 keeps database schema 3 and version 2 portable pages; no new database migration is required. Pen changes are preferences, not changes to existing strokes. The app preserves previously saved pens and recovers v0.3.0's detached current settings when necessary.

## Verification and device feedback

The Windows harness checks pen-edit persistence, legacy preference recovery, independent pen/highlighter settings, add/cancel behavior, wheel color and touch input, vertical-slider behavior, rail reachability across window sizes, scratch-out fixtures and undo, lasso actions, and database recovery. The release pipeline validates embedded versions, packages x64/ARM64, checks x64 standalone startup, renders the actual interface, and verifies uploaded assets before publishing.

Physical handwriting, palm rejection, and scratch-out comfort still need feedback on individual Surface devices. ARM64 is cross-built; native execution checks run on x64. Scribble detection remains a heuristic, and Undo/off controls are available.
