Download one of the application files under **Assets**:

- **SurfaceNotebook-windows-x64.exe**: Intel or AMD Windows PCs and Surface devices.
- **SurfaceNotebook-windows-arm64.exe**: Snapdragon/ARM Windows PCs and Surface devices.

Double-click the downloaded `.exe` to run. Each application includes .NET 10; no ZIP extraction, SDK, or separate runtime installation is needed. Windows may hide `.exe`, displaying the file as an **Application**.

To check your processor type, open Windows **Settings > System > About > System type**.

### Included

- One ruled page with pressure-sensitive handwriting.
- Four pen colors, adjustable thickness, and whole-stroke erasing.
- Inverted-tip eraser support, undo/redo, and clear page.
- Manual save/open of editable `.stempage` files.
- Optional mouse drawing for testing without a pen.

### Prototype limitations

Pages must be saved manually. Autosave, multi-page notebooks, touch panning/zooming, PDF tools, and AI are not included yet. Pen latency and palm behavior still need validation on actual Surface hardware.

The Windows build and automated storage, history, and WPF initialization checks run before publication. The bundled x64 executable also undergoes a startup/layout/rendering check. The ARM64 executable is cross-built; its startup and pen behavior need testing on an ARM device.

`SHA256SUMS.txt` contains checksums for both application downloads.
