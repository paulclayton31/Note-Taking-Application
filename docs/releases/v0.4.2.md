# v0.4.2 — File drops and circuit transcription checks

- Drop PNG/JPEG/BMP/GIF/TIFF files onto a page. Multiple files are inserted in one undoable operation; GIF/TIFF use the first frame.
- Copy image files in Explorer and paste them into the page, as well as browser images/bitmap clipboard content.
- Dropped PDFs insert their first page as an image; use Import PDF for complete PDF notebooks. Dropped .stempage files insert editable page content.
- Reject unsupported files and failed batches before changing page content. Up to 16 files per batch and existing page/image limits apply.
- Strengthen wire tracing instructions for Gemini. A locally detected circuit with branches connected only through ground now asks for wiring clarification instead of displaying a numerical answer. This conservative guard catches the reported split-node interpretation; such branches can also be legitimate circuits. An explicit diagram confirmation permits those legitimate cases; editing the question clears the confirmation.
- Clarify that checked circuit equations do not independently verify the AI's reading of the image. No claim of universally correct AI answers or model fine-tuning.

Windows regression checks cover file insertion, Explorer copy/paste, undo, corrupt/unsupported files and split-wire clarification alongside the known correct 60/7 V circuit. Live Gemini transcription accuracy still depends on the input image and model.
