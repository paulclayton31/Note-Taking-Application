# Surface Notebook v0.3.0-preview.1

The first preview of the new paper-first workspace: a calmer library, floating writing tools, real paper formats, and light and dark themes, built on the existing pen and offline autosave foundations.

## Download

- **Intel / AMD Surface:** [SurfaceNotebook-windows-x64.exe](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.0-preview.1/SurfaceNotebook-windows-x64.exe)
- **Snapdragon / ARM Surface:** [SurfaceNotebook-windows-arm64.exe](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.0-preview.1/SurfaceNotebook-windows-arm64.exe)

Close the old app, download the matching executable, and open it. No separate .NET installation is required. Use a named executable under Assets; Source code downloads do not contain the runnable app.

## Try the new workspace

- **Paper:** Letter, A4, Legal, or custom sizes; portrait or landscape; blank, college ruled, wide ruled, graph, dots, and engineering graph. Preview spacing and colors before applying them to a page or every page in a notebook.
- **Writing tools:** pressure or monoline pen, translucent highlighter, whole-stroke or precision eraser, native lasso selection with move/resize, line/rectangle/ellipse/arrow construction, typed text, and a hand tool. The default pen keeps the existing pressure and curve settings.
- **Floating palette:** use the color-and-chevron button for tool properties. Drag its grip, dock it at the top or bottom, or hide and reveal it.
- **Organization:** notebook switching, live page thumbnails, page-name search, favorites, and up to twelve open page tabs. Closing a tab does not delete a page.
- **Focus:** press **F11** or use the focus icon to collapse navigation and maximize writing space; **Esc** exits. The moon/sun button switches themes without changing page or ink colors.
- **Navigation:** fingers always pan or pinch to zoom. Continue scrolling past a page edge to turn pages, or use the footer arrows / Alt+Up and Alt+Down. Click the zoom percentage to fit the whole page; right-click it for width fit and 100%.

## Storage and compatibility

The preview upgrades the existing local library and creates **library-v02-backup.db** before its first v0.2 migration. Committed ink, notebooks, and saved page positions are retained. Original v0.1/v0.2 `.stempage` files import; new exports include paper, highlighter attributes, and typed text.

This is a preview. v0.2 remains the stable release. After migration, the older app cannot open the upgraded library directly; the backup preserves the pre-upgrade database. The [preview guide](https://github.com/paulclayton31/Note-Taking-Application/blob/main/docs/v0.3-workspace.md) covers the library and recovery behavior.

## Validation and current scope

Windows builds and automated checks cover legacy migration and backup, paper geometry, ink/text history, highlighter persistence, precision eraser identities, shape construction, background autosave/retries, killed-process recovery, pen-only input, palm suppression, touch navigation, notebook/page switching, themes, focus, and responsive WPF rendering. The packaged x64 executable also passes startup and screenshot capture checks. ARM64 is cross-built; physical pen feel and ARM64 execution still need checking on a Surface.

This preview uses one active paper page with edge-based page turning. Continuous stacked-page scrolling, folders, split view, PDF annotation, AI, and computational STEM objects remain future work. No inactive AI or split-view controls are shown.
