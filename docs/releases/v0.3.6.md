# Surface Notebook v0.3.6

A compact saved-color bar for faster pen switching.

Choose colors from the floating bottom bar instead of three saved-pen shortcuts on the main toolbar. Selecting a color resumes Pen and keeps the current thickness and Fountain/Ball style. Use + to add a color with the wheel, or right-click/hold a swatch to remove it. Up to 24 colors persist across restarts; overflow scrolls horizontally. Existing pen colors initialize the palette and existing presets remain in the customization rail. The bar stays above a bottom-docked toolbar and follows Hide writing tools.

This stable release builds on v0.3.5. The experimental Calculate tool remains exclusive to the v0.4 preview line. Notes, pressure, PDF support, pen preferences, schema 4, portable page version 3, and existing migration backups are preserved.
