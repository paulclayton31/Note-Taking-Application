# Surface Notebook v0.3.4

More forgiving scribble erase, especially for up-and-down scratches.

## Download

- **Intel / AMD Surface:** [Windows x64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.4/SurfaceNotebook-windows-x64.exe)
- **Snapdragon / ARM Surface:** [Windows ARM64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.4/SurfaceNotebook-windows-arm64.exe)
- [SHA-256 checksums](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.4/SHA256SUMS.txt)

Close the old app, download the matching executable, and open it. Your library remains at **%LOCALAPPDATA%\SurfaceNotebook**. No separate .NET installation is needed.

## What changed

v0.3.3 could reject intentional scratches because it expected sharp turns, a nearly full-length finishing pass, and enough coverage of the entire handwriting stroke. It could also miss repeated passes that stayed inside the target's bounds.

- **Rounded turns work.** A narrow scratch can turn smoothly instead of requiring sharp corners.
- **Shorter scratches work.** Three quick passes can finish with a shorter last pass; small scratches are accepted more readily. Horizontal, vertical, and diagonal directions use the same detection.
- **Local contact replaces whole-stroke coverage.** A narrow scratch can erase connected handwriting without covering a percentage of its total length. It must still actually touch the ink.
- **Passes count inside the target.** The scratch no longer needs to leave and re-enter the handwriting's bounding box for each pass.
- **Undo and Redo remain available.** One Undo restores erased content and the scratch mark; a second Undo removes the scratch.

Keep the pen down for a short back-and-forth scratch over the handwriting. Two deliberate reversals are still required to distinguish a scratch from a single return stroke. Scribble erase can be disabled in tool options.

Repeated circles/ovals, ordinary-writing fixtures, tiny jitter, blank gaps, distant ink, and long diagram lines have regression checks. Detection remains a heuristic; real Surface handwriting feedback is still useful.

## Existing features and compatibility

PDF import/export, saved pens, notebook/page management, and other v0.3.3 features remain available. Database schema **4** and portable page version **3** are unchanged. Libraries older than schema 4 receive the existing **library-v032-backup.db** backup before migration. App versions that do not support schema 4 cannot open the upgraded library.

## Verification

Windows checks cover rounded scratches at multiple sizes, angles, and sampling densities; uneven finishing passes; repeated contact inside a target; narrow contact with dense connected ink; negative fixtures; Undo/Redo; and restart persistence. The full existing library, input, PDF, and recovery suite also runs.

Release preflight builds x64/ARM64, validates executable versions, runs a bundled PDF export/import check during x64 startup verification, and captures the actual interface. ARM64 is cross-built; runtime checks run on x64.
