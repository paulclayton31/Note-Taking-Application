# Surface Notebook v0.4.0-preview.1

An experimental Calculate tool turns reviewed handwriting into editable numerical calculations.

## Download

- [Windows x64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.4.0-preview.1/SurfaceNotebook-windows-x64.exe)
- [Windows ARM64 executable](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.4.0-preview.1/SurfaceNotebook-windows-arm64.exe)
- [SHA-256 checksums](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.4.0-preview.1/SHA256SUMS.txt)

This is a **prerelease**. v0.3.5 remains the stable download. Close the app before opening a different version. The preview uses the existing local SurfaceNotebook library; keep a backup of that library when trying it. Executables are standalone, with no separate .NET installation required.

## Try it

1. Write `F = m * a`, `m = 2`, and `a = 3` on separate lines.
2. Select **Calculate** (calculator icon, shortcut **C**), circle the handwriting, and choose **Review selection**.
3. Check Windows' recognized text and correct any mistakes. The preview calculates **F = 6**.
4. Choose **Add to page**. Your original handwriting stays intact and the calculation saves as an editable card.
5. With Calculate selected, tap the card, change `m` to `4`, and choose **Update calculation** for **F = 12**. Undo restores the earlier formula and result.

**Type calculation** works even when handwriting recognition is unavailable. Handwriting recognition runs locally through Windows' installed handwriting service. Its accuracy depends on the writing and installed language support; review every number, name, and operator before accepting.

The calculator supports variables, formulas above their inputs, arithmetic, powers, percentages, parentheses, scientific notation, common functions, and explicit error messages. Each card has its own variables. Its source and results survive restart, copying, page/notebook duplication, and portable-page round trips. PDF export includes the visible result card.

## Scope and compatibility

- Numerical arithmetic with up to 12 significant digits displayed. Names are case-sensitive; trigonometry uses radians.
- No units, symbolic equation solving, graphs, or automatic updates from later handwriting changes in this preview. Edit the reviewed card source to recalculate.
- Standard lasso actions, Surface Pen barrel selection, shape holds, PDF backgrounds, pen preferences, and pen-only writing remain available. Fingers continue to navigate, with palm suppression.
- Database schema **4**, portable-page version **3**, and existing migration backups are unchanged. Optional calculation metadata lives with the text object. Older app versions display the cached text but may discard editable formulas when resaving it.
- PDFsharp-WPF stays pinned to **6.2.4**; PDFium and its third-party notices remain bundled. The Windows target now includes the Windows 10 19041 API contract for local handwriting recognition.

## Validation

Portable calculation checks cover evaluation, variable dependencies, precedence, functions, recognition symbols, invalid input, numerical domains, and resource limits. The Windows application harness adds calculation review, Undo/Redo, source-ink/pressure preservation, independent copies, restart and portable-page persistence, PDF export, touch filtering, and temporary barrel selection with Calculate active. It reports handwriting-service availability separately from mathematical evaluation.

Release preflight runs those checks, packages x64/ARM64, checks executable versions, verifies bundled x64 startup, PDF support, calculation, and handwriting-service initialization, and captures the actual calculation interface. ARM64 is cross-built; native runtime checks run on x64. Physical Surface handwriting, language-pack behavior, and ARM64 execution still need device feedback.
