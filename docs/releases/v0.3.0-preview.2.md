# Surface Notebook v0.3.0-preview.2

This update makes the writing toolbar easier to position and changes document tabs to represent notebooks.

## Download

- **Intel / AMD Surface:** [SurfaceNotebook-windows-x64.exe](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.0-preview.2/SurfaceNotebook-windows-x64.exe)
- **Snapdragon / ARM Surface:** [SurfaceNotebook-windows-arm64.exe](https://github.com/paulclayton31/Note-Taking-Application/releases/download/v0.3.0-preview.2/SurfaceNotebook-windows-arm64.exe)

Close the previous app before opening the new download. Your existing notebooks, ink, and paper settings are retained. There is no additional database schema migration from preview.1.

## Changes

- **Move the toolbar with its dotted grip.** The handle has a full 44-DIP touch target and accepts finger, pen, or mouse dragging. The previous grip's icon did not provide a usable hit-test surface.
- **Your toolbar position is remembered.** Placement survives reopening, resizing, portrait/landscape layouts, side panels, and focus mode. The palette stays inside the workspace. Use its properties menu for explicit **Move toolbar to top** and **Move toolbar to bottom** actions. Keyboard users can focus the grip and use arrow keys; Shift+arrows makes smaller adjustments.
- **One tab per notebook.** Selecting or creating pages updates the active notebook without creating tabs. Each notebook remembers its last-used page, including after restarting or closing and reopening its tab. Closing a tab keeps the notebook and all its notes.
- **Existing page tabs are consolidated automatically.** Tabs saved by preview.1 become one tab for each distinct notebook.
- **Search resets when switching notebooks.** A filter from the previous notebook no longer leaves the new notebook looking empty.

## Testing and review

The Windows checks cover notebook-tab consolidation, page switching without extra tabs, remembering the last page after cache eviction/restart, closing/reopening notebook tabs, real-window grip hit testing, mouse/touch drag events, docking, toolbar boundaries, saved placement, and portrait/compact/focus/panel layouts. Existing ink, pressure-data, eraser, text, paper, autosave retry, and killed-process recovery checks remain in place.

The standalone x64 app is also checked for startup and screenshot capture. ARM64 is cross-built. Physical Surface Pen latency and real hardware touch/pen gestures still need device validation.

See the [test and usability review](https://github.com/paulclayton31/Note-Taking-Application/blob/main/docs/reviews/v0.3.0-preview.2.md) for findings and suggested next improvements.
