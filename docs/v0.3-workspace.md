# v0.3 workspace preview

## Design

Warm paper is the center of the workspace. Neutral chrome and a restrained indigo accent keep navigation secondary. Dark mode changes the surrounding interface independently of paper and ink. Standard physical dimensions are represented in 96-DPI page coordinates, so resizing and zooming preserve the page's aspect ratio and existing ink.

The collapsible left library holds notebooks, page-name search, favorite filtering, and page thumbnails. Notebook tabs sit above the workspace. Switching pages stays within the same tab, and each notebook remembers its last-used page after closing/reopening or restarting. Older page tabs are consolidated automatically. Search/favorite filters reset when switching notebooks. The right context panel currently hosts paper settings; future tools can use this space without reserving distracting inactive buttons.

The palette floats above the paper. Its properties popover shows controls for the selected tool. Drag the dotted 44-DIP grip with a finger, pen, or mouse; the palette stays in the workspace and remembers its position. Its menu provides separate top/bottom docking actions. Keyboard users can focus the grip and use arrows (Shift+arrows for smaller steps). Relative placement survives resizing, rotation, side-panel changes, and focus mode. Tool targets are 44 DIPs. Panels and popovers use short transitions, respecting the Windows animation setting for panel fades. Paper and ink have no ancestor bitmap cache or visual effect.

## Writing and navigation

| Action | Control |
| --- | --- |
| Pen / highlighter / eraser | P / H / E |
| Lasso / shape / typed text / hand | L / S / T / V |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| New page / import / save now | Ctrl+N / Ctrl+O / Ctrl+S |
| Show/hide library | Ctrl+B |
| Focus / leave focus | F11 / Esc |
| Previous / next page | Alt+Up / Alt+Down or footer arrows |
| Pan / zoom | One finger / two-finger pinch |
| Mouse scroll / zoom / horizontal pan | Wheel / Ctrl+wheel / Shift+wheel |
| Fit page / width fit / actual size | Click zoom percentage / right-click its menu |

Fingers never create ink, shapes, or text, including while selection or text is active. Pen proximity suppresses touch movement for palm rejection. The hand tool additionally permits pen and mouse dragging.

The default pen retains the prototype's native WPF real-time DynamicRenderer, pressure response, and curve fitting. Monoline disables pressure only for subsequent strokes. Highlighter uses native WPF highlighter composition and a rectangular tip. Precision erasing gives split fragments unique identities. Lasso transforms replace identities before recording history so undo restores the old geometry.

Shapes use a pen drag from one corner/end to the other, then normalize to editable ink on release. Text accepts a mouse click or pen tap on paper; choose Text again to edit it. Text content, size, color, and position are stored independently from ink. Select ink or text with the lasso to move or resize it. Text editing supports native text undo; leaving the text box commits one document-history step.

There is one active page. Continued vertical movement beyond an edge turns to the adjacent page; a pinch never turns pages. This is paged navigation, not a continuous stacked-page view.

## Paper settings

Use **Paper** to open a live draft preview. Choose Letter, A4, Legal, or a custom width/height of 3–36 inches. Portrait and landscape swap the dimensions. Templates include blank, standard college/wide ruled, graph, dots, and engineering graph (major lines every five grid cells). Grid spacing is 8–96 page DIPs. Standard ruled templates use physical line spacing.

Paper and line colors accept #RRGGBB or #AARRGGBB. Preset background swatches provide warm/pure white, cream, sage, and dark paper. Ink color stays under your control; choose white or another light ink for dark paper.

Changes are applied explicitly to the current page or the entire notebook. Applying to the notebook also sets the template for newly created pages. Changing size preserves ink coordinates; a smaller page can crop ink from view without deleting it.

## Persistence

The library remains at **%LOCALAPPDATA%\SurfaceNotebook\library.db**. A single background worker serializes all writes and retains the v0.2 retry and clean-shutdown behavior. Ink writes remain incremental per collected stroke. Text drafts save after a short typing pause and commit when changing tools, pages, or closing. Preferences persist theme, library visibility, toolbar position/docking, open notebook tabs, each notebook's last-used page, and favorites.

The first migration from schema 1 creates a consistent SQLite backup at **library-v02-backup.db**, then adds page paper/text metadata transactionally. Schema 2 is not readable by v0.2. For rollback, close all app copies and keep the upgraded database and its sidecar files together; restore the backup to a separate library directory before replacing any working library. Normal preview use requires no file copying.

Page export is version 2 JSON with ink, physical dimensions, paper settings, and typed text. Version 1 imports continue to work. A live page-session cache holds five pages. Frozen thumbnail drawings are bounded, refreshed after idle, and deferred while the pen is in range.

## Engineering map

- `Themes/DesignSystem.xaml` and `WorkspaceTheme` contain shared visual tokens and control templates.
- `PaperSettings`, `PageText`, and the versioned `PageDocument` are WPF-independent data contracts.
- `PaperSurface` draws templates once per retained visual and supports the settings preview and thumbnails.
- `PenCanvas` and `PageViewport` own device filtering and navigation; page content stays in page coordinates.
- `MainWindow` partials separate the library lifecycle, writing tools, and workspace UI.
- `NotebookDatabase` and `AutosaveWriter` retain transaction and failure recovery responsibility.
- `PreviewCapture` renders screenshots from a temporary sample library, never the user's notes.

The context panel and typed-object model provide room for later STEM/AI work. Split view needs separate view/session state per pane; it is not implemented in this preview.

## Review on Surface

Compare handwriting to v0.2 before evaluating the new controls. Try palm contact in each tool, pinch near the page edges, lasso movement followed by undo/reopen, precision erase followed by undo, typed text after reopening, notebook-wide paper changes, and focus mode in portrait and landscape. Actual device latency, ARM64 execution, and comfort during a long lecture session need physical device feedback.
