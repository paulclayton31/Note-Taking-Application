# v0.3 workspace

## Design

Warm paper is the center of the workspace. Neutral chrome and a restrained indigo accent keep navigation secondary. Dark mode changes the surrounding interface independently of paper and ink. Standard physical dimensions are represented in 96-DPI page coordinates, so resizing and zooming preserve the page's aspect ratio and existing ink.

The logo, notebook tabs, and window controls share one 52-DIP header. Click the logo to open **Home**: a dedicated library with notebook covers, nested folders, breadcrumbs, global name/folder-path search, recently opened and starred notebooks, and a **Continue writing** shortcut. Create notebooks in the current folder, or use a card's **…** menu to rename, star, or move it. Folder menus rename or move entire folder branches; invalid cyclic moves are prevented. Sorting offers recent activity or name. The rail collapses in narrow windows. Home and the last writing page are remembered across restarts.

The writing sidebar holds a notebook picker, page-name search, favorite filtering, and page thumbnails. Switching pages stays within the same tab, and each notebook remembers its last-used page after closing/reopening or restarting. Older page tabs are consolidated automatically. Search/favorite filters reset when switching notebooks. Overflowing tabs can be swiped horizontally or scrolled with the mouse wheel; keyboard selection reveals the selected tab. Closing a tab keeps its notebook and notes. The right context panel currently hosts paper settings; future tools can use this space without reserving distracting inactive buttons.

The palette floats above the paper with all seven tools in one row. Tap a tool to switch, then tap the active tool again to open a slim customization sidebar. The settings button opens the same inspector; starting to write closes it. On compact windows it overlays the page to preserve the writing viewport. Saved pens appear directly on the palette when there is room. Drag the dotted 44-DIP grip with a finger, pen, or mouse; the palette stays in the workspace and remembers its position. The inspector provides separate top/bottom docking actions. Keyboard users can focus the grip and use arrows (Shift+arrows for smaller steps). Relative placement survives resizing, rotation, side-panel changes, and focus mode. Tool targets are 44 DIPs. Panels use short transitions, respecting the Windows animation setting for panel fades. Paper and ink have no ancestor bitmap cache or visual effect.

## Writing and navigation

| Action | Control |
| --- | --- |
| Pen / highlighter / eraser | P / H / E |
| Lasso / shape / typed text / hand | L / S / T / V |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| New page / import / save now | Ctrl+N / Ctrl+O / Ctrl+S |
| Show/hide library | Ctrl+B |
| Focus / leave focus | F11 / Esc |
| Previous / next page | Alt+Up / Alt+Down or footer arrows |
| Pan / zoom | One finger / two-finger pinch |
| Mouse scroll / zoom / horizontal pan | Wheel / Ctrl+wheel / Shift+wheel |
| Zoom presets / slider / fit page / fit width | Tap the footer zoom percentage |

Fingers never create ink, shapes, or text, including while selection or text is active. Pen proximity suppresses touch movement for palm rejection. The hand tool additionally permits pen and mouse dragging.

The default pen retains the prototype's native WPF real-time DynamicRenderer, pressure response, and curve fitting. Monoline disables pressure only for subsequent strokes. Highlighter uses native WPF highlighter composition and a rectangular tip. Precision erasing gives split fragments unique identities. Lasso transforms replace identities before recording history so undo restores the old geometry.

Tap the active **Pen** tool or settings button to find **Your pens**. Save a named pen with the current color, thickness, and pressure/monoline style, then tap it to reuse it. Right-click or long-press a saved pen to rename or remove it. Up to 12 presets are supported. The color button opens the inspector's swatch grid and custom hex-color field. Current pen, highlighter, and eraser settings also survive reopening. Existing strokes retain their original attributes when a preset changes.

Tap a lasso selection for **Copy**, **Duplicate**, **Delete**, or **Paste**, including copies across pages. A tight scribble with the pen can erase covered handwriting or typed words; one Undo restores both the content and the mark. Turn scribble erasing off in pen settings when desired. See the [writing tools guide](writing-tools.md) for shortcuts, undo behavior, and touch interaction details.

Tap the footer's zoom percentage for a 25–400% slider, 50/75/100/150% choices, **Fit width**, and **Whole page**. Zoom stays anchored at the viewport center. The adjacent −/+ buttons and pinch gestures remain available. Entering focus mode preserves the writing zoom.

Use the page header's **…** button, or right-click/long-press a page row, to **Duplicate page**, **Move earlier**, or **Move later**. A duplicate appears immediately after its source with independent editable ink/text, the same paper, and the same view. Mouse and pen users can also drag the small page thumbnail onto another page to reorder it. Fingers scroll the list; the menu provides touch reordering. Moving a page preserves the active page and writing view.

Shapes use a pen drag from one corner/end to the other, then normalize to editable ink on release. Text accepts a mouse click or pen tap on paper; choose Text again to edit it. Text content, size, color, and position are stored independently from ink. Select ink or text with the lasso to move or resize it. Text editing supports native text undo; leaving the text box commits one document-history step.

There is one active page. Continued vertical movement beyond an edge turns to the adjacent page; a pinch never turns pages. This is paged navigation, not a continuous stacked-page view.

## Paper settings

Use **Paper** to open a live draft preview. Choose Letter, A4, Legal, or a custom width/height of 3–36 inches. Portrait and landscape swap the dimensions. Templates include blank, standard college/wide ruled, graph, dots, and engineering graph (major lines every five grid cells). Grid spacing is 8–96 page DIPs. Standard ruled templates use physical line spacing.

Paper and line colors accept #RRGGBB or #AARRGGBB. Preset background swatches provide warm/pure white, cream, sage, and dark paper. Ink color stays under your control; choose white or another light ink for dark paper.

Changes are applied explicitly to the current page or the entire notebook. Applying to the notebook also sets the template for newly created pages. Changing size preserves ink coordinates; a smaller page can crop ink from view without deleting it.

## Persistence

The library remains at **%LOCALAPPDATA%\SurfaceNotebook\library.db**. A single background worker serializes all writes and retains the v0.2 retry and clean-shutdown behavior. Ink writes remain incremental per collected stroke. Text drafts save after a short typing pause and commit when changing tools, pages, or closing. Preferences persist theme, library visibility, toolbar position/docking, open notebook tabs, each notebook's last-used page, favorites, pen presets/current writing settings, and whether Home was open. Page duplication and reordering use SQLite transactions on the same ordered worker.

The first migration from schema 1 creates a consistent SQLite backup at **library-v02-backup.db**, then adds page paper/text metadata transactionally. Upgrading preview.1/preview.2's schema 2 creates **library-preview2-backup.db** before adding folders, notebook stars, and recent activity in schema 3. Backups are written atomically. Older releases cannot read schema 3. For rollback, close all app copies and keep the upgraded database and its sidecar files together; restore the matching backup to a separate library directory before replacing any working library. Normal preview use requires no file copying.

Page export is version 2 JSON with ink, physical dimensions, paper settings, and typed text. Version 1 imports continue to work. A live page-session cache holds five pages. Frozen thumbnail drawings are bounded, refreshed after idle, and deferred while the pen is in range.

## Engineering map

- `Themes/DesignSystem.xaml` and `WorkspaceTheme` contain shared visual tokens and control templates.
- `PaperSettings`, `PageText`, and the versioned `PageDocument` are WPF-independent data contracts.
- `PaperSurface` draws templates once per retained visual and supports the settings preview and thumbnails.
- `PenCanvas` and `PageViewport` own device filtering and navigation; page content stays in page coordinates.
- `MainWindow` partials separate the library lifecycle, writing tools, and workspace UI.
- `NotebookDatabase` and `AutosaveWriter` retain transaction and failure recovery responsibility.
- `PreviewCapture` renders screenshots from a temporary sample library, never the user's notes.

The context panel and typed-object model provide room for later STEM/AI work. Split view needs separate view/session state per pane; it is not implemented in this preview.

## Review on Surface

Compare handwriting to v0.2 before evaluating the new controls. Try palm contact in each tool, pinch near the page edges, lasso movement followed by undo/reopen, precision erase followed by undo, typed text after reopening, notebook-wide paper changes, and focus mode in portrait and landscape. Actual device latency, ARM64 execution, and comfort during a long lecture session need physical device feedback.
