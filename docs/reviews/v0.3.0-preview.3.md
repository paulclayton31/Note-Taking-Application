# Workspace test and usability review

Reviewed October 24, 2026 using the Windows WPF application, isolated libraries, actual control events, an offscreen native window for popup/input checks, and rendered application layouts.

## Implemented and checked

| Area | Evidence |
| --- | --- |
| Compact header and tab X | Logo, tabs, and window controls share 52 DIPs. Checked long notebook names at widths 640/960/1440, centered close-button bounds, all four glyph arms at 100/125/150/200% raster scale, and the actual close/reopen action. |
| Home | Opened nested folders and notebook cards through their controls; checked breadcrumb structure, folder-path search, stars, notebook moves/renames, cycle rejection, and restart state. Reviewed light and dark rendered screens. |
| Pens | Saved/applied a color/width/monoline preset, compared existing stroke pressure/attributes before and after, and reopened to verify settings. |
| Zoom | Opened the actual dismissible popup with a native owner window; changed the slider, checked center anchoring, fit controls, zoom bounds, and focus-mode zoom preservation. |
| Pages | Copied ink including pressure, text, paper, and view; verified new object identities, immediate insertion after the source, independent editing, transactional reorder, invalid-order rejection, and restart order. |
| Storage | Opened a schema 2 fixture, verified unchanged ink/paper and a readable schema 2 backup. Checked rejected library mutations leave the save queue usable. Existing autosave retry and killed-process recovery checks remain. |
| Input | Existing pen-only filtering, palm suppression, touch pan/zoom, toolbar hit testing/movement/docking, and ink/text history checks remain. PenCanvas and PageViewport were not modified. |

Testing also exposed and fixed a compiled context-menu event wiring failure, off-center/clipped tab controls, focus mode resetting the writing zoom, stale thumbnail drag state, and a light Home-selection brush persisting in dark mode. The screenshot path now waits for rendered notebook covers before capturing a theme change.

Screenshots use sample notes in temporary libraries. The tests do not open the user's live notebook database. Raster-scale checks confirm glyph geometry; they do not replace moving a real window between monitors with different Windows display scales. ARM64 is cross-built, while local execution and standalone smoke testing use x64.

## Next improvements to evaluate on Surface

1. **Palette orientation and handedness.** A vertical option and left/right placement presets could reduce interference during long writing sessions.
2. **Home cover customization.** Let students choose notebook colors/covers after validating the folder and recent-notebook workflow with real coursework.
3. **PDF import alongside notes.** This is the next substantial academic workflow; plan per-pane page/view state before adding split view.

Physical pen latency, real palm contact, long-press comfort, and sustained touch navigation still need a real Surface session. The new features should be judged against the existing handwriting feel first.
